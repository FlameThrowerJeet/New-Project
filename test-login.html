How to Test

  1. Start the React development server: cd client && npm start
  2. Open the application in your browser
  3. You'll see the login screen with "Flame Thrower Jat" title
  4. Enter any of the valid credentials above
  5. The system will verify the Aadhar number and first name
  6. Upon successful login, you'll see the main dashboard with your name in the status bar

Test Cases

  • Valid Login: Use any of the credentials above
  • Invalid Aadhar: Try any 12-digit number not in the list
  • Wrong Name: Use correct Aadhar but wrong first name
  • Empty Fields: Try submitting with empty fields
  • Invalid Format: Try Aadhar numbers with less than 12 digits
