# 🤖 Scribe: Automatic Session Tracker & Auto-Fill System

## Overview

The **Scribe** component is the 4th tab in the SessionsTracker (MissionTracker) that provides intelligent screen recording, activity tracking, and automatic session summarization. It automatically fills the Sessions tab with AI-generated summaries of your work activities.

## Features

### 🎬 Screen Recording
- **One-click recording**: Start/stop screen capture with simple buttons
- **Display capture**: Records your entire screen or selected windows
- **Activity detection**: Tracks mouse movements, keyboard input, and application interactions
- **Screenshot capture**: Takes periodic screenshots during recording sessions

### 🧠 AI-Powered Summarization
- **Activity analysis**: Converts tracked interactions into meaningful activity descriptions
- **Session summaries**: Generates human-readable summaries of work sessions
- **Focus scoring**: Calculates productivity scores based on activity levels
- **Key actions extraction**: Identifies main tasks performed during sessions

### ⚡ Auto-Fill Integration
- **Smart session matching**: Automatically matches recordings to MissionTracker time slots
- **Seamless integration**: Updates Sessions tab in real-time
- **Confidence scoring**: Tracks reliability of auto-generated content
- **Manual override**: Allows editing of auto-filled content

## How It Works

### 1. Starting a Recording Session

1. Navigate to the **SCRIBE** tab in MissionTracker
2. Click **"Start Session Recording"**
3. Grant screen capture permissions when prompted
4. The system begins recording and activity tracking

### 2. During Recording

The Scribe actively monitors:
- **Mouse movements** → Navigation activity
- **Keyboard input** → Text/data entry
- **Application switches** → Context changes
- **Scroll activity** → Content review
- **Click interactions** → User engagement

### 3. Session Completion

When you click **"Stop Recording"**:
1. Recording stops and data is processed
2. AI generates a summary based on detected activities
3. Focus score is calculated (30-95% based on activity level)
4. Session automatically fills the appropriate MissionTracker slot
5. Data is saved for history and review

### 4. Auto-Fill Process

The system automatically:
- Identifies the current time slot in MissionTracker
- Finds the matching session (within 1-hour tolerance)
- Generates formatted summary with key activities
- Updates the session notes with `[Auto-generated by Scribe]` tag
- Triggers UI refresh to show updated content

## Technical Implementation

### Data Flow
1. **MediaRecorder API** → Screen capture
2. **Activity Listeners** → User interaction tracking
3. **AI Summarization** → Content generation
4. **LocalStorage Integration** → Data persistence
5. **Event System** → Real-time UI updates

### Storage Structure
```typescript
// Session recordings stored in localStorage
interface SessionRecording {
  id: string;
  startTime: string;
  endTime?: string;
  duration?: number;
  activities: string[];
  summary: string;
  keyActions: string[];
  focusScore: number;
  screenshots: string[];
  status: 'recording' | 'processing' | 'completed';
}

// Auto-fill tracking
interface AutoFilledSession {
  sessionId: number;
  dayNumber: number;
  content: string;
  timestamp: string;
  confidence: number;
}
```

### Event System
- `mission-tracker:update` → Triggers MissionTracker refresh
- Real-time updates between Scribe and Sessions tabs
- Automatic data synchronization

## Privacy & Security

### Local Processing
- All activity tracking happens locally
- No data sent to external servers
- Screen recordings stored temporarily in browser memory

### User Control
- Recording requires explicit user permission
- Can stop recording at any time
- Auto-generated content can be manually edited
- Screenshot data is limited and cleaned up automatically

### Data Retention
- Session history limited to last 50 recordings
- Screenshots limited to 5 per session
- Old data automatically cleaned up

## Troubleshooting

### Common Issues

**Recording won't start**
- Check browser permissions for screen capture
- Ensure you're using a modern browser (Chrome, Firefox, Edge)
- Try refreshing the page

**Auto-fill not working**
- Verify MissionTracker has today's sessions initialized
- Check that current time matches a session slot (±1 hour)
- Ensure localStorage has sufficient space

**Performance issues**
- Limit number of concurrent browser tabs
- Clear old session data periodically
- Disable other screen recording software

### Browser Compatibility
- ✅ Chrome 72+
- ✅ Firefox 66+
- ✅ Edge 79+
- ❌ Safari (limited MediaRecorder support)
- ❌ Internet Explorer (not supported)
